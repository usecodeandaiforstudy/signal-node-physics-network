# RBF 粒子神经网络

一种将每个神经元设计为 2D 空间可移动粒子的神经网络架构。每种数学运算都有直接的模拟电路对应——从底层设计上确保整个网络可以在 CMOS + 忆阻器芯片上原生运行。

## 为什么重要

标准神经网络无法在模拟硬件上高效运行，因为其核心运算（ReLU、softmax、矩阵乘法链）在电路中实现代价高昂。更根本的是，**反向传播**——训练所有现代神经网络的算法——需要存储完整计算图并计算精确梯度，这在模拟系统中物理上不可行。

本项目采取相反的路径：**围绕模拟电路天然擅长的运算设计网络架构**，然后开发不依赖反向传播的训练方法。

## 关键结果

| 指标 | 数值 |
|---|---|
| **参数效率** | ~150 参数达 ~92%（4D 分类），MLP 需 ~1,300 参数才能匹敌（~9x 优势） |
| **天然 2D 数据** | 同心圆 100%，Moons 99.3% — 仅需 4 个粒子 (69 参数) |
| **器件估算** | 最优配置 (6/4/3 粒子) 约 100 晶体管 + 12 忆阻器 |
| **功耗估算** | μW 级（亚阈值工作） |
| **推理延迟** | 纳秒级（全模拟信号通路） |
| **噪声鲁棒性** | "none" 到 "high" 噪声仅降 < 2% 准确率 |
| **训练方法** | 3 种：标准反向传播、SPSA（2 次测量/迭代）、HiMAL（无跨层梯度） |

消融实验发现：粒子数从 4 增至 25，2D 基准准确率零提升，仅增加参数冗余。

## 设计

每个神经元是一个三元组 `(xc, yc, h)`——2D 坐标加影响半径。四个参数全部可训练。前向传播仅使用六种基本运算：

```
运算                电路等价                        器件开销
────────────────────────────────────────────────────────────
(x - xc) / h       → 差分放大器                     ~4 晶体管
dx² + dy²          → Gilbert 乘法器                  ~6 晶体管
exp(-k · d²)       → BJT 亚阈值 I-V                 1-2 晶体管
z / Σz             → 电流镜除法器                   4 晶体管 + 导线
W · z              → 忆阻器交叉阵列                 无源（仅忆阻器）
f + δ              → 导线汇合（基尔霍夫）             0 器件
```

三层堆叠加残差连接构成 **ResidualRBFNetwork**。高维扩展 **ProjectedRBFEnsemble** 使用固定随机投影将 D 维数据映射到多个 2D 子空间，每个子空间由独立的 RBF 网络处理并取平均。

## 训练方法

项目提供 **三种** 训练方式，对数字基础设施的依赖递减：

| 方法 | 需要反向传播？ | 每次迭代前向次数 | 物理可行性 |
|---|---|---|---|
| **标准 (autograd)** | 是 | 1 | 仅数字域 |
| **SPSA** | 否 | 2 | 高 — 仅需测量损失值 |
| **HiMAL** | 否 | 2 × N_params（每层约150） | 高 — 逐层独立 |

## 实验证明链

```
1. 数字基线      → Moons 96%+，旋转回归 R² 98%+（20 粒子）
2. 物理前向验证    → 模拟器与数字模型相关度 >0.95
3. 噪声容忍度      → 四种噪声水平下准确率稳定
4. SPSA 训练     → 仅 2 次前向测量达到反向传播 ~95% 精度
5. HiMAL 训练    → 逐层训练达到端到端 ~90% 精度
6. 2D 分类       → 同心圆 100%，Moons 99.3%（4 粒子，69 参数），含决策边界图
7. 投影集成       → 4D 数据 ~92%（~150 参数），MLP 需 ~1,300 参数才能匹敌
```

**7 项全部通过 → RBF 粒子网络可在纯模拟物理系统中实现训练+推理完整闭环。**
