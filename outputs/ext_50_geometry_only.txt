  **THE OWED ITEM, in 12.28's own words:** "a true 'calibrate, do not search' arm would
  remove those coordinates from the parameter vector -- a change to `get_params_vector`,
  a base method -- and that is NOT done.  The measurement BOUNDS the gain from below
  rather than measuring it."

  **`get_params_vector` is `centers (D*N) + h (N) + W_gauss (n_vars*N) + W_act (n_vars*N)`,
  so the strengths are the last `2*n_vars*N` entries and the mask is exact rather than
  approximate -- asserted against the layer's own shape before any arm runs.**

  **AND BOTH THE PERTURBATION AND THE UPDATE ARE MASKED.**  Masking only the update
  would let `L(theta + eps*delta)` differ from `L(theta - eps*delta)` through coordinates
  that never move, which BIASES the estimate instead of restricting it.

  Cost: every arm pays `2 * spsa_avg * epochs * layers * 2 networks` forward passes --
  **equal FORWARDS, not equal steps or equal wall time.**

====================================================================================================
  P4  VERDICT AND LIMITS
====================================================================================================

  `get_params_vector` was NOT changed -- the base method is untouched.  What changed is
  the ARM, which now masks the perturbation and the update to the geometry subspace,
  asserted against the layer's own layout before running.  **12.28's owed change is
  therefore DONE, and done without editing the base version**, which is the same
  monkey-patch discipline `ext_43` already used.

  **THE LIMITS.**  One task, one architecture, one scale -- the extension's standing
  limitation, unchanged.  The search is still SPSA with one averaging and one
  perturbation size, both inherited from the shipped trainer and never tuned, so the
  relative standing of three arms is a statement about THOSE settings.  And the arms are
  compared at equal forwards, which is the project's unit but not the only defensible one:
  per-step, the geometry-only arm updates fewer coordinates.
