==================================================================================================
  WHAT THE DEFECT COSTS
==================================================================================================

  run                      original  geometry excluded   cells affected
  ----------------------------------------------------------------------
  40 epochs, 9 seeds           8/14               8/14             0/14
  160 epochs, 1 seed           6/14               7/14             2/14

  the epoch axis, ORIGINAL criterion : 8/14 -> 6/14 (-2)
  the epoch axis, CORRECTED          : 8/14 -> 7/14 (-1)

  THE DEFECT IS EPOCH-DEPENDENT, and it INFLATED the epoch effect.
  At 40 epochs no cell has `geometry` as its best search arm, so the
  correction changes nothing there (8/14 either way).  At 160
  epochs 2 of 14 do, and excluding geometry moves the count from
  6 to 7.  So part of what looked like a real epoch effect was the
  criterion comparing the hybrid against itself.  The honest statement of the
  epoch axis is the CORRECTED one: 8/14 -> 7/14.

  WHAT THIS DOES NOT CHANGE: the do-no-harm GUARANTEE is untouched -- worst
  hybrid R^2 is still never below its own geometry arm, which is what the
  guarantee claims.  What changes is only the stronger, empirical claim about
  beating the competing methods.

  THE STATED LIMIT: excluding `geometry` is the correction THIS audit argues for,
  not a criterion the base version endorsed.  An alternative is to keep geometry
  in the set and report cells where it dominates separately; both fix the same
  problem and neither is chosen here by measurement, because the choice is about
  what the sentence is meant to claim.
