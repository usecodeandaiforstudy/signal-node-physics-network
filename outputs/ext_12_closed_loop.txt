  Input dimension D = 4, so the designed probe set needs 6 readings
  per node at minimum; this run uses 6, i.e. 6 x 40 = 240 readings for the loop.

  THREE ARMS, and the difference between the last two is the whole point:
    A open loop   plan, place, deploy the planned strengths
    B accept      measure, ADOPT the measured geometry, re-solve strengths
    C correct     measure, estimate the actuator's gain, re-command, re-solve
  B is what ext_11 showed fails: adopting a uniformly-shrunk node set does
  not restore the functions the basis no longer spans.  C makes the device
  realize the intended geometry instead.
