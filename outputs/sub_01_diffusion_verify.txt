  Read this carefully.  In the ideal limit BOTH substrates agree with the
  digital model; in float32 both are rounding-limited at ~1e-7.  The
  difference is not the size of the number, it is what the number means:
    circuit   : exp() comes from a behavioural device model, so agreement
                is a statement about the simulator's arithmetic, and the
                exponent scaling (v_t = 1.0) has to be assumed perfect
    diffusion : exp() IS the Green's function of a real PDE, so the same
                agreement is a statement about physics, and Part 1 checks
                the kernel against an independent PDE solve

====================================================================
  PART 2: superposition -- the 'combine' step is a physical law here
====================================================================
  12 signed point sources, amplitudes N(0,1), at random positions
  test                                                       relative error
  --------------------------------------------------------------------------
  field(all) - [field(even) + field(odd)]                         2.858e-16
  vectorised sum - literal one-source-at-a-time loop              0.000e+00

  Both are at float64 rounding level, i.e. the layer's sum over particles
  is EXACT.  This is what makes 'activate then combine' a physical law on
  this substrate rather than a circuit that approximates a sum: the PDE is
  linear, so no intermodulation, no saturation, no cross-talk terms exist.
  A thresholded medium (an excitable/spiking substrate) would fail exactly
  this test, and that is the check to run before adopting any new medium.

====================================================================
  PART 3: the Green's-function prefactor and why calibration is needed
====================================================================
  cell: D=0.001 m^2/s, h=0.5 input units -> 0.500 mm
  narrow-channel delay t = h^2/(4 k D) = 125.00 us
  per-source calibration gain g = (4 pi D t)^(dim/2) = 1.2533e-03

  injection scheme                               max abs error vs digital
  --------------------------------------------------------------------------
  q_ij = W_ij * g_j   (calibrated)                              5.915e-08
  q_ij = W_ij          (not calibrated)                         9.976e+00

  The uncalibrated error is the per-source prefactor variance: sources with
  different widths have different peak amplitudes, so forgetting g_j scales
  each particle's contribution by a different factor.  Physically g_j is a
  pulse energy, so the calibration is a per-source amplitude setting -- but
  it must be redone every time a width h_j changes, i.e. on every training
  step that touches a width.  That is the real cost this substrate adds.

  Boundary design rule (isolated source at the centre of a reflecting cell):
    cell width / h    boundary-induced rel. error
  ------------------------------------------------
               2.0                      2.713e-01
               3.0                      2.222e-02
               5.0                      7.453e-06
               8.0                      2.531e-14
              12.0                      0.000e+00
              20.0                      0.000e+00

  A reflecting cell must therefore be roughly an order of magnitude wider
  than the kernel, or the returning field has to be subtracted explicitly
  with image sources (which is what the n_images setting does).

  The operative rule is the distance from the SOURCE to the nearest wall,
  not the cell width -- a particle sitting against a wall sees its own image
  at twice that distance no matter how big the cell is:
    source-to-wall / h    boundary-induced rel. error
  ----------------------------------------------------
                   0.5                      6.065e-01
                   1.0                      1.353e-01
                   1.5                      1.111e-02
                   2.0                      3.355e-04
                   3.0                      1.523e-08
                   5.0                      0.000e+00

  The trained model above sits in a cell whose half-width is 3.84 mm while its outermost particles are at 3.20 mm,
  i.e. source-to-wall/h - 1.4, which is exactly
  the regime where the table still shows a per-cent effect.  Layout, not
  cell size, is what protects the kernel.

  positive-only medium (thermal-like) cannot inject negative strengths.
  Realised as two identical cells with opposite drive, then subtracted:
    field measurements per probe block: signed=4, differential=8 (2.0x)
  Carrier diffusion needs no such scheme: electrons and holes give both signs.

====================================================================
  PART 6: measurement cost model (field measurements per layer per block)
====================================================================
  probes inside a block are read in parallel by a sensor array, so the cost
  is per block and not per input sample.

  substrate / scheme                              measurements   vs naive
  ------------------------------------------------------------------------
  diffusion, strength-encoded, signed, dual channel             4      0.06x
  diffusion, strength-encoded, differential, dual             8      0.13x
  diffusion, per-particle naive readout, dual               62      1.00x
  analog-circuit substrate (memristor MVM, one shot)             1      0.02x

  N=30 particles, n_vars=1, use_pu=True
  strength encoding turns the readout matrix into per-source pulse
  amplitudes, so ONE injection computes a whole output channel: the
  measurement count depends on the number of OUTPUTS, not on the number
  of particles.  Speedup vs the naive per-particle readout: 15.5x.
  The partition-of-unity denominator costs one extra unit-strength
  measurement; that is the price of PU on any field substrate.

  [assert] all 7 enforced thresholds hold -- the physical claims that
  sections 2, 3 and 8 of FINDINGS.md rest on are intact.

  What this establishes, and what it does not:
   + a second substrate implements the same network with a byte-identical
     parameter vector, so trained weights move across media unchanged
   + the kernel is verified against a PDE solve, i.e. as physics
   + superposition is exact, so the combine step is a physical law
   + cross-substrate trade-off, measured rather than asserted:
       diffusion : kernel exact, superposition exact, but n_vars+1 field
                   measurements per block
       circuit   : ONE shot for the whole readout (memristor crossbar),
                   but exp() is a behavioural device model, not a PDE
   - this is a numerical substrate: the Green's function is evaluated in
     closed form.  Real cells add timing jitter, temperature drift of D,
     and source-size effects, none of which are modelled here
   - the numbers assume the geometry printed in Part 5; they are
     illustrations of the scaling laws, not device specifications
