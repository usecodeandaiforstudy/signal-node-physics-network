  WHY: ext_24 could not answer section 11's tail because `effective_budget`
  derives the per-epoch budget from the architecture, so raising N raised the
  budget too (600 -> 1200 -> 2500) and moved the hybrid curve's FIRST point
  (1200 -> 2400 -> 5000) past the 3000 grid point.  At N=208 the low-budget
  comparison was UNDEFINED, not bad.  Passing an explicit budget fixes it:
  the first point is then identical for every N.

  AND IT INTRODUCES A RISK: a fixed budget can be too small for a bigger network.
  `budget` is probes per epoch and each probe costs 2 forward passes, so a full
  sweep of an N-particle layer needs 2*(D+2)*N forward passes -- at budget 600 an
  N=208 layer manages 0.24 sweeps/epoch.  Section 7 of the base reports exactly
  this situation as INCONCLUSIVE.  So every cell is checked against the 0.05
  learning floor and a cell that fails it is NOT counted as a win.

  runtime archs added: ['S52', 'S104', 'S208']
